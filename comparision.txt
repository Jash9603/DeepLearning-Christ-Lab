
Effect of learning rate

The learning rate decides how fast the model updates itself.

If learning rate is too small:

Learning is slow
Loss decreases very gradually
If learning rate is too large:

Loss can jump up and down
Model can become unstable
In these results, the learning rate is balanced:

Loss decreases smoothly
No sudden jumps
Final output is clean and correct

Final Region Graph

All three models (Keras, PyTorch, TensorFlow low-level) learned the XOR pattern correctly.

The color regions show that:

The model separates diagonal points correctly
A non-straight (non-linear) boundary is learned

Training loss graphs
